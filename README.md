# Anonymous Board · RP Companion v0.2.6

SillyTavern 的独立扩展：一部「虚拟手机」，里面装着两个匿名论坛——日语的 2ch 和英语的 4chan。你可以发帖、回帖，让模型扮演一群网友来回复——可以用酒馆当前连接的模型，也可以给论坛单独配一个 API。不依赖任何预设，不改提示词，也不往聊天记录里写东西。

## 安装

**推荐：在酒馆里直接安装**

1. 打开酒馆顶部的「扩展 / Extensions」（三个方块的图标）→「安装扩展 / Install extension」。
2. 粘贴这个链接，点安装：`https://github.com/geminidawn007/AnonymousBoard-ST`
3. 装好后刷新网页，屏幕右侧会出现一个圆角玻璃小按钮（面具对话气泡图标）。
4. 在酒馆「API 连接」里连上一个模型；或者在论坛的「設定 / Settings」→「AI 来源」里填一个独立 API。

**更新**：「扩展」→「管理扩展 / Manage extensions」里找到 Anonymous Board，点更新按钮。帖子和设置都保存在浏览器里，更新不会丢。

**手动安装**：在本页点 Code → Download ZIP，解压后把整个文件夹放到 `SillyTavern/data/default-user/extensions/`（多用户时把 `default-user` 换成你的用户目录），刷新酒馆。

从 v0.1 升级：先删掉旧的扩展文件夹，再按上面的方法安装。旧帖子会在第一次加载时自动迁移（旧版保存的窗口坐标不会迁移，那正是手机上窗口跑出屏幕的原因）。

## 打开方式

- 点悬浮按钮。
- 酒馆左下角魔杖菜单 →「匿名掲示板」。
- 斜杠命令 `/anonboard`。
- 酒馆「扩展」面板里的「匿名掲示板 · Anonymous Board」→「打开论坛」。

## 悬浮按钮

- **拖动**：按住拖到任何位置，松手后自动贴到最近的左/右边缘。按钮只会停在酒馆顶栏和底部输入框之间，不会挡住发送按钮，也不会跑出屏幕；旋转屏幕或改变窗口大小后会重新定位。
- **收起**：长按按钮，它会滑进屏幕边缘只露一条；点一下展开。设置里可以开「闲置时自动收起」。
- **未读角标**：关着论坛时生成完的回复会在按钮右上角显示红色数字，按钮会轻微呼吸发光。
- 按钮在酒馆侧边抽屉打开时会被抽屉盖住，不会反过来遮挡酒馆界面。
- 不想要按钮可以在设置里隐藏，之后用魔杖菜单或 `/anonboard` 打开；「扩展」面板里也能重新显示或重置位置。

## 虚拟手机界面

- 电脑上是一部可拖动（拖顶部状态栏或标题栏）、可调整大小（拖右下角）的手机。
- 手机或矮窗口上自动变成全屏 App，适配刘海屏安全区、横屏，以及软键盘弹出时的可视高度。
- 顶部状态栏（时间、信号、电量）、标题栏、帖子列表、楼层回复、底部导航（スレ一覧／スレ立て／設定，4chan 为 Catalog／New thread／Settings）。
- 帖子里的工具栏：回到列表、跳到开头／末尾、**新着／Update**（召唤网友回复）、**書く／Reply**（写回复）。
- 点楼层号：引用回复、查看谁回复了这层、复制、删除。点 `>>12` 这类引用会弹出被引用的那一层。
- 配色可选：经典、夜间、跟随系统。

## 板块

两个论坛都可以选板块。点列表页标题（板名旁边的 ▾）打开板块列表，或者在「スレ立て / New thread」表单最上面的「板 / Board」里选择发到哪个板。每个板的帖子分开显示，列表里会标出各板的帖子数和新回复数。

- **2ch**：ニュー速VIP（默认）、なんでも実況J、ニュース速報+、芸スポ速報+、恋愛サロン、オカルト、大学生活、アニメ。
- **4chan**：/b/ - Random（默认）、/a/ - Anime & Manga、/v/ - Video Games、/tv/ - Television & Film、/mu/ - Music、/lit/ - Literature、/adv/ - Advice、/x/ - Paranormal、/fit/ - Fitness、/ck/ - Food & Cooking。
- 每个板有自己的默认名字（例如なんJ是「風吹けば名無し」）和氛围说明，生成时会告诉 AI 现在在哪个板、这个板的人怎么说话。模型如果还是写成通用的「名無しさん／Anonymous」，会自动换成这个板的默认名字。
- 4chan 除了 /b/ 以外都是全年龄板块，和真 4chan 一样用蓝色的 Yotsuba B 版面，AI 也会收敛露骨内容。
- **自定义板块**：在板块列表最下面点「＋ 自定义板块」，填板块名称、默认名字和板块说明。说明会作为这个板的设定发给 AI，所以可以做成剧情世界里的论坛，例如「桜ヶ丘学園的校内匿名版，住民都是在校学生」。自定义板块可以随时编辑或删除，删除后板里的帖子会移到默认板。
- 以前的帖子会归到默认板（ニュー速VIP 和 /b/）。

## AI 来源（可随时切换）

在论坛的「設定 / Settings」最上面选择，或者在帖子右上角「⋯」菜单里一键切换：

- **跟随酒馆**：用酒馆当前的模型和 API 连接（通过 `generateRaw`）。设置页会显示当前连的是哪个模型。
- **独立 API**：论坛单独用一个兼容 OpenAI 接口的服务，和酒馆主聊天互不影响。
  - **API 地址**：例如 `https://api.openai.com/v1`。也可以直接点常用地址：OpenAI、DeepSeek、OpenRouter、硅基流动、本地 Ollama、LM Studio。粘贴完整的 `…/chat/completions` 也会自动修正。
  - **API Key**：本地模型可以留空。
  - **模型名称**：手动填写，或点「获取列表」从服务端读取后搜索选择。
  - **连接方式**：
    - 「经酒馆转发」（默认）：请求由酒馆服务器代发，不受浏览器跨域（CORS）限制，绝大多数服务直接可用。插件会用你填的 Key 覆盖掉酒馆为自己「Custom」来源保存的 Key，所以酒馆里存的 Key 不会被发到这个地址。
    - 「浏览器直连」：浏览器直接请求 API。适合酒馆装在远程服务器、模型跑在你自己电脑上的情况；服务端必须允许跨域。
  - **温度**：0–2，默认 1.0。
  - **测试连接**：发一条很短的消息，告诉你是否连通、用时多久；失败时会说明原因（Key 不对、地址或模型不存在、额度用完、跨域被拦截、连不上等）。
- 某些模型不接受 `max_tokens` 或自定义温度，遇到这类 400 错误时插件会自动去掉这两个参数重试一次。
- 切换只影响之后的生成；正在生成中的那一批会用开始时的来源完成。

## 论坛时间（跟随剧情）

论坛的日期和时钟默认跟着你的 RP 走，不再使用现实时间。比如剧情发生在 2015 年，帖子的日期、手机状态栏的时钟、版面标题下的日期都会显示 2015 年，网友也只知道那个年代的事和网络用语。

- **跟随剧情**（默认）：插件在本地读取最近 40 条聊天、作者注释（Author's Note）和角色卡的「场景」，从里面找日期和时间。角色卡「描述」里只认带「时间／日期」标签的写法，避免把角色的出生年份当成故事年份。这些内容不会被发送到任何地方，和「剧情参考」开没开无关。
  - 能识别的写法举例：`【时间】2015年3月14日 星期六 21:30`、`📅 2015年10月28日 周三 ⏰ 晚上9点04分`、`二〇一五年三月十四日 下午三点半`、`2015-03-14 21:30`、`2015/3/14(土) 22:05`、`平成27年3月14日 午後9時30分`、`March 14, 2015, 9 pm`、`凌晨两点`、`中午1点`。
  - 最新的信息优先：日期取最近一条写了日期的消息，钟点取不早于那条消息的时间。年份如果只写在角色卡场景里（例如「故事发生在2015年的东京」），也会用上。
  - 剧情里的时间一变（比如写了「第二天 3月15日 早上8点」），论坛马上跟着变。剧情时间没变的时候，论坛时钟会像真手机一样继续走，最多走 3 小时，不会跑太远。
  - 哪部分没找到（例如只写了钟点、没写年份），就用现实时间补上那一部分。设置页会写清楚每部分是从哪条消息里认出来的。
- **手动设定**：自己选一个日期和时间，论坛时钟从那里开始跟现实一样往前走。
- **现实时间**：和以前一样用设备时间。

**发过的帖子时间固定不变**，只有论坛的「现在」跟着剧情走。比如晚上 9 点半到 10 点半在论坛聊过，之后剧情推进到第二天早上，再打开论坛，那些帖子还是前一天晚上的时间，新的回复才会是第二天早上的。剧情回到过去（回忆、倒叙）也不会改动已有的帖子。同一串里新帖子的时间不会早于前面的帖子。

剧情里只写了「第二天」「翌日」「the next morning」，或者只写了一个比当天更早的钟点（例如前面写着 3月14日 21:30，后来只写「早上8点」），论坛会按第二天算。

想挪动整串帖子的时间（例如以前按现实时间发的串），在帖子「⋯」菜单里选「调整这串的时间」：设定第一帖的时间，或者一键让最后一帖落在论坛现在，整串一起平移，帖子之间的间隔不变。

## 两个论坛有什么不同

| | 2ch | 4chan |
|---|---|---|
| 默认语言 | 日语 | 英语 |
| 默认名字 | 名無しさん | Anonymous |
| 版面 | 灰底、红色标题、绿色名字、蓝色锚点（默认ニュー速VIP，可换板） | /b/ 用 Yotsuba 米色栗色，其他全年龄板用蓝色 Yotsuba B（默认 /b/，可换板） |
| 楼层 | 1、2、3… 顺序编号，`>>1` 锚点 | 九位数全站帖号，`>>931116524`，引用 OP 显示 (OP)，引用你显示 (You) |
| 身份 | 每人一个 ID，显示同 ID 发言次数，连投 5 次以上 ID 变红 | 无 ID，人人都是 Anonymous |
| 特色 | 勢い（热度）、sage 不顶帖、あぼーん（删帖留痕）、颜文字、イッチ、草 | greentext（`>` 开头的绿字）、catalog 缩略图、backlinks、黑色幽默、跑题 |
| 语气 | 短句吐槽、ツッコミ、揚げ足取り | 小写、毒舌、kek/based/cope、总有人跑题 |

两个论坛的帖子分开保存。设置里可以把回复语言改成中文或另一种语言，但论坛文化保持不变。

## 设置（论坛内「設定 / Settings」）

- AI 来源；论坛时间（跟随剧情／手动设定／现实时间）。
- 两个论坛各自的回复语言；配色。
- 网友语气：温和（基本友善，会帮你出主意，最多轻轻调侃）／普通（默认：有好有坏，每批最多一两条吐槽，不会人身攻击你）／毒舌（原汁原味的匿名版，嘴很毒）。论坛文化（短句、锚点、greentext、黑话、跑题）在三档里都保留，只改态度；帖子「⋯」菜单里也能随时切换，之后的回复生效。
- 每次召唤的回复数：1–200，可以直接输入，也可以点或按住 −／+ 调整。超过 10 条时会每 10 条一批接着生成：每批都会读到前面几批的回复，让讨论继续下去，而不是所有人都回同一句话；每批的回复长度也不会超出模型的输出上限。生成过程中会显示进度（例如 `10/25`），再点一次「新着 / Update」或进度旁的「中止 / Stop」，这一批写完就停。
- 发帖后是否自动获取回复。
- 剧情参考：不读取／最近聊天（条数可调）／剧情摘要（读取酒馆「Summarize」扩展的最新摘要，没有时改读最近聊天）。剧情只作为「作者背景」发给模型，网友不会当成自己知道的事。
- 公共设定：写下这个世界里人人都知道的事实，网友会当作常识。
- 悬浮按钮：自动收起、显示／隐藏、重置位置。
- 数据：导出／导入 JSON 备份（也能导入 v0.1 数据）、清空全部帖子。

## 和主剧情的隔离

- 「跟随酒馆」时，回复用 SillyTavern 的 `generateRaw` 单独生成，带自己的系统提示词，不使用当前预设的提示词内容、世界书或角色卡；温度等采样参数和模型沿用你当前的连接设置。
- 「独立 API」时完全不经过酒馆的生成流程，用的是论坛自己的模型、Key 和温度，不会占用酒馆正在进行的生成。
- 不写入聊天记录，不注入提示词，不修改任何设置。
- 在论坛里打字时按键不会传给酒馆（不会误触滑动、重新生成等快捷键）。
- 样式全部限定在插件内部，不影响酒馆主题。

## 数据与隐私

- 「跟随剧情」识别时间只在浏览器本地进行；发给模型的只有识别出的日期和时刻，不包含聊天内容。
- 帖子保存在当前浏览器的 `localStorage`，不在 SillyTavern 服务器上。清除网站数据会丢失；换设备不会同步——请用导出／导入。
- 开启「剧情参考」时，选定的聊天内容会随提示词发送给当前使用的模型服务（酒馆的连接或你的独立 API）；选「不读取」即可关闭。
- 独立 API 的 Key 以明文保存在这个浏览器的 `localStorage` 里，导出备份时会被去掉。在公用电脑上用完请清空 Key。

## 兼容性

- 已在 SillyTavern 1.19.0（桌面 1440×900、手机 390×664、横屏 844×390）测试。
- 代码也处理了 1.13 之前旧版 `generateRaw` 的参数格式，但没有在旧版酒馆上实测。
- 独立 API 已用一个模拟的 OpenAI 兼容服务测试过两种连接方式和各种出错情况，没有对接真实服务商实测。
- 模型偶尔不按 JSON 格式回复时，插件会尽量从输出中挽救可用的帖子；仍失败会提示重试。

## 卸载

删除扩展文件夹。浏览器里保存的帖子需要另外清除网站数据（或先导出备份）。
